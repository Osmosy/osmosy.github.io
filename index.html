Vector

Экосистема AI-агентов на базе Hermes Agent (Nous Research): прикладные департаменты — от юридического до заводского цеха — и инфраструктура их развёртывания. Всё локально, данные не покидают периметр.

Прикладные департаменты
Vector Legal
Юридический AI-департамент: 12 плагинов, 167 навыков, полный перенос Claude-for-Legal под право РФ. ГК, 152-ФЗ, ТК, АПК, Роспатент.
Vector Marketing live diagram
Маркетинговое AI-агентство: 16 профильных агентов под управлением CMO-оркестратора. Кампании, аналитика, контент, прогнозы.
Vector Work live diagram
Виртуальные сотрудники: 17 доменов Cowork (Anthropic), 212 навыков — legal, finance, HR, engineering, design, data.
Vector Meat live diagram
Мясоперерабатывающий завод: 13 виртуальных работников, ХАССП, Меркурий/Честный ЗНАК, 5 стадий ИИ-трансформации.
Vector Health
Единая медицинская библиотека навыков: 1508 скиллов из 4 открытых источников + DICOM-анализ.
Vector Gene
Персональная геномика с AI-агентами: FASTQ → варианты → ClinVar/gnomAD → AlphaMissense. Всё локально.
Vector Office
Офисный инструментарий виртуальных работников: Word, Excel, PowerPoint без офисного пакета (OfficeCLI).
Vector 1C
Навыки и инструменты для 1С:Enterprise — конфигурации, расширения, внешние обработки, отчёты.
Vector Home
Офлайн умный дом: голос/текст → GPT-2 парсер → Home Assistant. Без облака и GPU, RU+EN.
Vector Voice
Голосовой слой: STT, TTS, intent recognition, диаризация. On-device, без облака (Moonshine Voice).
Vector Agent-Ready
Методология подготовки контента для ИИ-агентов: 7 слоёв — предсказуемые URL, машиночитаемые слои, редакторский порядок. Сайты, репозитории, базы знаний.
Инфраструктура
Vector Grace
GRACE-методология: knowledge graph, grep-first навигация, semantic markup, frontier→слабая LLM пайплайн.
Vector SkillOpt
Автоматический оптимизатор навыков: train the procedure, not the weights (на базе Microsoft SkillOpt).
Vector Deck Themes
15 дизайн-тем презентаций + универсальный движок дек. python-pptx, кириллица, dark/light.
Archify (fork)
Диаграммы для агентов: validated architecture/workflow/sequence/dataflow/lifecycle как интерактивный HTML.
